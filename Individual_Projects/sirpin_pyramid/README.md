# Sierpinski Triangle
***
This project is for drawing custom Sierpinski triangles using the turtle library. It lets you set the turtle’s color and size, choose the recursion depth, and draw. The program uses user input to creat a drawing of a sierspinki triangle.
## Project photo
![photo](documents/Screenshot%202026-03-02%207.36.26%20PM.png)  

## How to use the project
- Use the menu to
- Set turtle color
- Set size
- Choose recursion depth
- Draw the triangle
- Exit or redraw
## Key features
- Custom Turtle Color
- Adjustable Pen Size
-  Recursion depth
- Redraw Option
## Installation instruction
- Runs on python
- use turtle library
