



# Document Word Count
***
This project is a program for managing your text documents. It lets you view the document, add new content, and update the word count and last edited timestamp. The program uses simple file handling to keep your documents organized.
***
## How to use the project
- use python
- enter the exact file path of your document If the file doesn't exist, it will be created.
-Use the menu to:
 - Update document info (adds word count and timestamp)
 - View document (see current content)
 - Add content (write new lines)
 - Exit the program

## List of Key Features
- 📄 View Document: Display your document's content.
- 📝 Add Content: Quickly append new lines to your document.
- 🕒 Update Info: Calculates and saves the word count and last-updated timestamp at the bottom of the file.
- 💾 Automatic File Handling: If the file does not exist, it is created automatically.
