## Grade Book
[Grade Book](docs/Screenshot%202026-03-30%208.27.56%20PM.png)  

***
This project is a program for managing your classroom grades. It lets you add students, record and update grades, and view class statistics and summaries. The program uses simple file handling to keep your grades organized and saved.
***
## How to use the project
- use python
- run the program; all files are created automatically in the docs folder
-Use the menu to:
- Add new students (stores name, ID, grade level)
- Record grades for each student
- View individual student records (see all grades and standing)
- View all students in a table
- View class summary and statistics
- Exit the program
## List of Key Features
- 👤 Add Students: Keep track of names, IDs, and grade levels.
- 📝 Add Grades: Record grades for each student (0-100).
- 📋 Student Records: Display all grades, average, and academic standing for any student.
- 📊 Class Stats: See class average, highest and lowest grade, and summary.
- 💾 Automatic File Handling: All student and grade data is saved automatically in the docs folder.
## Installation instructions
- it runs on python
- only csv and os libraries are needed
